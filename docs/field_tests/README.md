# 현장 점검 기록 (2026-11-01 ~ 11-03)

> 11/7 학습 데이터 녹화(1~4차)의 회차별 정리는 [`2026-11-07/`](2026-11-07/README.md)에 있습니다.

보드 점검 화면에서 읽은 값을 그대로 옮겼습니다. 학습용 데이터가 아니라, 장비·배치·무선 상태를 판단한 근거입니다. 엑셀에서 바로 열리도록 UTF-8(BOM) CSV로 저장했습니다.

| 파일 | 한 줄 = | 내용 |
|---|---|---|
| `runs.csv` | 점검 한 번 | 날짜, 순서, 장소, 배치, 노드·게이트웨이 펌웨어, TX-1 전원, 사람 움직임, 명령, 메모 |
| `measurements.csv` | 점검 한 번의 노드 하나 | 초당 수, 신호 세기, 무선 손실, 거리, 자리 |

`run_id`로 두 파일을 잇습니다.

## measurements.csv 칸

| 칸 | 뜻 |
|---|---|
| `path` | `usb`: 노드를 USB로 노트북에 연결, `gw`: 무선 노드를 게이트웨이로 받음 |
| `source` | `check 명령(10초)` 또는 `gateway 명령(5초)`. 두 명령이 보여 주는 값이 다릅니다 |
| `verdict` | `check`의 판정(`정상`/`확인 필요`). `gateway` 명령은 판정이 없어 빈칸 |
| `csi_lines`, `csi_hz` | `check`: 수집 도구가 받은 CSI 줄 수와 초당 수. `gateway` 행의 `csi_hz`는 게이트웨이가 그 노드에서 받은 초당 수 |
| `tx_hz_est` | TX-1 패킷 번호로 추정한 송신 속도(정상 약 90~100) |
| `values` | CSI 값 개수(서브캐리어 192개 × 2) |
| `rssi_mean/min/max` | 노드가 TX-1 패킷에서 잰 신호 세기(dBm). `check`에서만 나옴 |
| `gw_received`, `gw_lost`, `loss_pct` | 게이트웨이가 받은 수, 노드 패킷 번호로 센 잃은 수, 손실(%) |
| `gw_rssi` | 게이트웨이가 그 노드에서 받은 신호 세기(dBm). `gateway` 명령에서만 나옴 |
| `dist_tx_m`, `dist_gw_m` | TX-1, 게이트웨이까지 거리(m). 223호 책상 배치는 정한 좌표, 실제 배치는 평면도(`docs/site/s4-1_2f_layout_1103.png`) 좌표로 계산한 추정값 |
